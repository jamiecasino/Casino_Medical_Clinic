# Casiño Medical Clinic — Website Draft

A responsive, one-page website concept built with HTML, CSS and vanilla JavaScript.

## Preview
Open `index.html` in a browser, or open this folder in VS Code and use Live Server.

## Before publishing
- Confirm the doctor's exact professional title, specialty, training, education and dates.
- Confirm the clinic's founding date, full addresses, phone numbers, operating hours and services.
- Confirm which location serves which patients and the current physician schedule process.
- Replace placeholder photography only with images cleared for use. Do not post patient faces or medical records without appropriate permission.
- Replace draft narrative with physician-approved wording.
- Consider bilingual English/Filipino text for accessibility.

## Editing
- Text and sections: `index.html`
- Colors, layout, fonts: `style.css`
- Mobile navigation: `script.js`

No appointment booking or patient data is collected in this draft.
